# History of our application "Cybersecurity Research Resources"

Three versions of the app were made during the development of this project:
- Version Zero
- Version One
- Version Two - The Final Version

## Version Zero

This version of the app is the simplest one—it had only two options: Add resource or Show resources. It did not even have a quit button. The program would eventually stop after the materials were shown. There were no categories in this version of the app.

## Version One

Version One differs from the previous one because it includes a quit button. It contains a loop so the program never ends unless the user selects quit.

## Version Two - The Final Version

The finished product. The completed app consists of 5 options in the starting menu. In comparison with the previous version, this one features an updated resource display table, clickable links for learning resources, and categorization.
